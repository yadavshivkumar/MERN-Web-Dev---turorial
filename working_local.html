Working with local storage in JavaScript

Local storage is a web storage API that allows you to store data in the browser. It provides a way to save key-value pairs in a web browser with no expiration date. This means that the data stored in local storage will persist even after the browser is closed and reopened.

To use local storage in JavaScript, you can use the `localStorage` object. Here are some common methods to interact with local storage:

<>
  • setItem(key, value): This method is used to store a key-value pair in local storage. The key is a string that identifies the data, and the value is the data you want to store. For example: 
    localStorage.setItem('username', 'JohnDoe');
