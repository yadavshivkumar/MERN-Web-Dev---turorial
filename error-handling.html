Error Handling in JavaScript

In JavaScript, you can handle errors using the try...catch statement. This allows you to catch and handle exceptions that may occur during the execution of your code.

Using try...catch

try {
    // Code that may throw an error
    let result = someFunction();
    console.log(result);
} catch (error) {
    // Code to handle the error
    console.error('An error occurred:', error);
}

In this example, if someFunction() throws an error, the catch block will execute, allowing you to handle the error gracefully.

Using finally

You can also use the finally block to execute code regardless of whether an error was thrown or not.

try {
    // Code that may throw an error
    let result = someFunction();
    console.log(result);
} catch (error) {
    // Code to handle the error
    console.error('An error occurred:', error);
} finally {
    // Code that will always execute
    console.log('This will always run.');
}

In this example, the code inside the finally block will execute whether an error occurred or not, making it useful for cleanup tasks.

Throwing Custom Errors

You can also throw your own custom errors using the throw statement.

function validateAge(age) {
    if (age < 18) {
        throw new Error('Age must be at least 18.');
    }
    return true;
}   
try {
    validateAge(16);
} catch (error) {
    console.error('Validation error:', error.message);
}

In this example, the validateAge function throws an error if the age is less than 18. The catch block then handles the error and logs the message.
