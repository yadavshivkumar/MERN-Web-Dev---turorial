Event Bubbling in JavaScript

Click on the child element to see event bubbling in action. You can also click on the parent element to see the parent click event. Try uncommenting the event.stopPropagation() line in the child click event listener to see how it affects event bubbling.

After 3 seconds, a new dynamic child element will be added. Click on it to see event delegation in action.

Note: The alerts will show the order of event handling. The parent click event will fire after the child click event due to event bubbling, unless you stop propagation.

Also, the parent click event will fire during the capturing phase if you set the third argument of addEventListener to true.

Feel free to experiment with the code and see how event bubbling, capturing, and delegation work in JavaScript!
