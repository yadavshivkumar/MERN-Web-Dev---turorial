Timer Interval

Click the "Start" button to start logging "Hello" to the console every second. Click the "Stop" button to stop the logging.


explanation: The setInterval function is used to execute a specified function repeatedly at fixed time intervals. In this example, when the "Start" button is clicked, it sets up an interval that logs "Hello" to the console every 1000 milliseconds (1 second).

The clearInterval function is used to stop the interval when the "Stop" button is clicked, preventing further logging of "Hello".

set Interval is useful for tasks that need to be performed repeatedly, such as updating a clock, fetching data at regular intervals, or creating animations. It continues to execute the specified function until it is stopped using clearInterval.

it is important to store the interval ID returned by setInterval in a variable (in this case, timerId) so that it can be used to clear the interval later.

it is also important to note that if the "Start" button is clicked multiple times without clicking "Stop", multiple intervals will be created, which can lead to unexpected behavior. To prevent this, you can disable the "Start" button after it is clicked and enable it again when the "Stop" button is clicked.
